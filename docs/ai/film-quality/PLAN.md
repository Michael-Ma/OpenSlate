# 视频质量提升计划

**状态：** 第 0–5 阶段都已完成并合并，结果见 [RESULTS.md](RESULTS.md)。音效只做了合成替代品，授权音效包未做。

2026-11-01。依据同目录的 `EVIDENCE.md` 和 5 份调研报告。所有排序和工期都是工程判断，未经实验验证。

## 诊断

| 排序 | 根因 | 证据 | 依据类型 |
|---|---|---|---|
| 1 | 导演看不到画面，切点盲切 | 模型把动作铺满整段，平均比计划晚 1.33 秒，而计划只取开头。躺倒、转身拒绝这些笑点都被切掉了 | 抽帧实测 |
| 2 | 开拍前没有故事设计 | 想讲「只对吃饭有动力」，但计划要求「正常速度」「不夸张」，反差被自己写没了。2 个模型 cold read 都读成「吃了西兰花」 | 模型读片，样本小 |
| 3 | 没有声音和字幕 | 需求要配乐，成片无音轨。有研究发现去掉音轨后，观众更容易察觉剪辑点 | 实测加文献 |
| 4 | 关键帧各生成各的 | 背景相似度片段内 0.886，跨切点 0.403。房间变化来自 8 张互不相干的关键帧，不是视频模型 | 实测 |
| 5 | Prompt 拼接方式错误 | 模型听顺序，不听秒数：8 段里只有 2 段按时完成。模板占 prompt 的 83–89% | 抽帧实测 |

## 分歧与处理

| 分歧 | 处理 |
|---|---|
| **用户的原判断是中英混杂导致质量差。** Prompt 调研认为这是症状：中文动作模型也执行了，五家厂商都没有效果对比 | 仍统一成英文，这也是根因修复的一部分。但不指望单靠它提升质量 |
| **用户的原判断是过渡生硬。** 剪辑调研发现主因是切错位置，`xfade` 实测会出现两只狗 | 先修切点，不加转场。`xfade` 全片最多一处，推迟 |
| **用户要求用关键帧作参考图、不强制首尾帧。** 连续性调研建议默认改回 `firstFrame`，Codex 和故事调研建议放开使用 | 默认仍是参考图。只在姿态本身就是笑点的镜头，导演可以不问就用首帧或首尾帧。不改回默认 |
| 故事调研要求 `ctx.shot` 强制填字段，缺字段就拒绝提交 | 先写进指引，看效果再决定。Codex 也提醒不要加门槛 |
| 连续性报告说 v6 关键帧尺寸未知，并按方图估算裁切损失 | 素材页实测是 941×1672，方图的估算不适用于这部片。代码模式的竖图参数仍要修 |

## 阶段

### 0. 重剪现有素材（已有试看版，$0）

只用现有 8 段重新选切点，加字幕。证明不用重新生成就能改善很多。缺的是真实音乐和音效。

### 1. 导演创作指引（约 2 天，高收益）

- 新增约 6 KB 的 `skills/code-plan/references/film-craft.md`，从 `skills/v8.1.0/` 的 craft-story、craft-comedy 等提炼。
- 开拍前先写 logline、节拍表，每拍写明必须看得见的画面。
- Prompt 规则：英文，单语言，60–90 词，不写秒数，不写物理尺寸，5 秒片段最多 2 拍，结尾写落点状态。
- 改 `example-plan.ts`，分离 `frame` 和 `motion`，不再做模板拼接。
- 每部片都要有音乐，时长放在主要动作完成之后再切。

**验收：** 同一条 brief 重做，cold read 能说出笑点。

### 2. 角色和场景锁定（约 2 天，图像阶段 $0）

- 先做 $0 实测：`ctx.image` 的 `references` 能否守住背景。
- 公开 `references`，增加竖图参数，计划阶段校验。
- 先出角色设定图和空房间 plate，所有关键帧都用它们作参考。

**验收：** 跨切点背景相似度明显上升。

### 3. 导演能看片（约 5 天，风险最高）

- 新增 `read_clip_frames` 工具，返回真实图片。
- **先验证：** `packages/director/src/tools/stdio.ts` 现在只返回文字，Director 模型能否收到 MCP image block 要实测，不通就换方案。
- 导演按画面选入点和出点，用 rubric 自查。单镜最多补拍 1 次，全片最多 2 次，不新增人工审核。

**验收：** 动作完成后才切的片段接近 8/8。

### 4. 渲染和声音（约 7 天）

| 项目 | 工作量 |
|---|---|
| 字幕：canvas 生成 PNG 再 `overlay`，固定开源字体 | 3 天 |
| 响度 `loudnorm` 和 fade-in | 0.5 天 |
| 定帧、整段变速 | 1 天 |
| 固定 punch-in（1.2–1.4 倍） | 0.5 天 |
| 音效来源 | 2–3 天，来源和授权待定 |

### 5. 模型对照（需要确认预算）

| 实验 | 花费 |
|---|---|
| `quality=high` 对比 `low`，含 $0 的 Codex 前置测试 | 约 $0.85 |
| `enhance` 开关 | 约 $2.10 |
| 中英文 prompt | 每镜约 $0.50 |
