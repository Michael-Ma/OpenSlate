# Done

## keyframes-codex-known-failure-reported-unknown

Saved native failures now return a definite execution failure with `technical: false`, `retryAllowed: false` and `taskId: null`. The existing engine failure handler sets phase `failed` and reservation `charged`, frees the installation-wide Codex slot, and refuses the double-charge release command. Reconciliation does not restart or repeatedly look up saved terminal failures.

The native worker returns sanitized codes for usage limits (`USAGE_LIMIT`), image failure/refusal (`IMAGE_FAILED`), failed turns (`TURN_FAILED`), interrupted turns (`TURN_INTERRUPTED`) and a completed turn with no image (`NO_IMAGE`). It confirms its bounded interrupt through exact native terminal history; interrupt acknowledgement without terminal evidence remains unknown. Validated terminal failures survive later cancellation or cleanup failure, including cancellation while the turn observation callback is pending. Invalid, foreign or ambiguous native history remains unknown.

The generation overview exposes the safe failure code and maps validated `USAGE_LIMIT` evidence to the existing `native_rate_limited` diagnostic. Consumed failures are not marked `notDispatched`; native thread/turn ids and refusal prose are not exposed.

## keyframes-codex-prepare-fence-unknown

Current lease ownership is now checked separately from selection, pause and hold eligibility. A worker with its exact unexpired submitting lease records `not_dispatched` when preparation or the marker transaction fails before dispatch. Stop, a prompt edit and an editing Director message produce a rejected execution outcome and a released reservation; the engine's existing terminal phase for rejected outcomes is `failed`.

A reconciler with a freshly claimed lease records the same no-start proof when no dispatch marker exists, whether or not native preparation was saved. The marker always precedes `turn/start`, and the new lease epoch fences an old worker still awaiting preparation. A stale/expired worker or a lookup without lease authority cannot create this proof. A real dispatch marker with no saved terminal evidence stays unknown.

Regression tests exercise the actual Stop, storyboard edit and Director request services, release/resume the relevant control or request hold, press scene generation again, and publish the fresh frame without charging the original reservation.
