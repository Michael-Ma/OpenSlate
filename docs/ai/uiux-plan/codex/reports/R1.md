# R1 — storyboard edits preserve paid media

## Done

- **plan-undo-outdates-paid-media:** removed the blanket brief/story Undo invalidation. Undo now checks each image/video kind's actual shot intent, corresponding prompt and shot presence before detaching it. A sceneId-only move no longer invalidates paid media. Existing narration, motion/duration/video-prompt and prompt-only exclusions, dependency propagation and exact-media restoration remain intact. Timeline/render still require rebuilding.
- **plan-delete-shot-running-job:** `deleteShot` uses the same shot-scoped `assertNoRunningAttempts` guard as `deleteScene`, before any state mutation. Running/unknown image, video and mapped section-speech attempts refuse deletion with `ATTEMPTS_RUNNING`. Terminal jobs permit deletion; removing the shot never dispatches a failed candidate's retry.
- **plan-import-confirm-project-hold:** successful import confirmation releases only the confirmation request's own holds inside the existing command transaction. Continuation lineage and publication checks remain unchanged. Already-authorized queued video elsewhere dispatches without another human press; confirmation creates no generation authority. Failed publication rolls back, and replay cannot release a newer request's holds.
