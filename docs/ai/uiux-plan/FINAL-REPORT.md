## 深度复查：Plan / 生成流程、界面代码和全部导演 skills

你要求在实现和真实测试之后，把整个 scene / shot 的计划与生成流程、剩下的界面代码和全部 skills 再审一遍。

### 怎么审的

- 一个 18 个 agent 的工作流，分 9 块：Plan 编辑、导演、关键帧、视频、配音、成片、界面、当前 skills、历史 skills。
- 每块先由审查者找问题，再由一个"怀疑者"逐条复核，尽量推翻。
- 大多数发现都用一次性测试实际复现过。
- 结果：42 条发现，确认 41 条，推翻 1 条。
- 全部证据在 `docs/ai/uiux-plan/review-flow/FINDINGS.md`。
- 我自己也读了付费路径、确认流程和 v6 skills，又补了两条：
  - 导演的界面指引还在用已删掉的 Storyboard / Timeline 名字（已修）；
  - 导演提议只改运动时，视频提示词不会跟着改（已修，见下）。

### 最严重的两条（都已修复）

1. **撤销会扔掉付费视频。** 撤销一次 Story 修改，或撤销一次跨场景移动镜头，会把整部片的关键帧和视频标成过期，只能再付一次 Viggle。现在撤销只在镜头的画面意图或提示词真的变了时才让媒体过期。
2. **付费任务被误报"没有回应"。** 三个以上任务同时收尾时，输出存储写满，已被 Viggle 接受的视频会被标成"没有回应"，并且不再查询，供应商那边的结果可能过期丢失。现在这只算本机繁忙，下一轮再处理，已放弃的旧任务也不会再挤掉新任务。

### 其他修复（按区域）

- **Plan 编辑**：镜头还有任务在跑时不能删除；确认导入后不再留下挡住整部片生成的锁。
- **关键帧**：
  - 重新生成失败、被 Stop 或被放弃后，会恢复原来的关键帧，视频可以用它；
  - Codex 生成明确失败（用量上限、图片被拒、超时、没有图片）时，记为已计费的失败，不再是要求"确认可能重复计费"的"没有回应"；
  - 准备阶段被 Stop、改提示词或导演消息打断，记为未开始、未计费，可以直接再按。
- **视频**：
  - 确认后改场景标题或别的镜头，不会再让排队中的视频永远停在"排队·下一个"；
  - 确认真的失效时，镜头显示"需要重新确认"；
  - Viggle 已完成但下载失败时显示原因，不再提供放弃按钮。
- **配音**：
  - 已付费、已完成的配音不会因为同场景的其他编辑或一条导演消息被丢下，下一次按也不会再买一遍；
  - 改了运动或时长后不再一直卡在 PLAN_COMPOSITION_STALE；
  - "生成关键帧"顺带生成配音的那次运行现在可见，一句太长的台词不再挡住其他镜头的配音；
  - 延长到合适长度的秒数和服务端一致，只估算过的台词不再给出必然失败的按钮。
- **导演提议**：
  - 横幅现在列出提议改动的每个字段（Now → After），按钮写"采用 N 处修改"；以前接受时看不到新台词或提示词；
  - 镜头还在生成时，提示"正在生成的内容会照常计费，结果会过时"；
  - 改运动或景别会按手动编辑的规则重写提示词，并显示在预览里；
  - 时长限制在 3–15 秒；
  - 无法采用的提议显示为已过期；
  - 用别的选项处理掉的提议会被拒绝，并释放它占用的锁；
  - 在当前契约下，导演不能绕过你直接改动会让付费素材过期的字段（PROPOSAL_REQUIRED）。
- **成片导出**：
  - 导出时限按片长放大，编码改用四线程（结果仍可复现），6 分钟的真实素材不会再超时；
  - FFmpeg 被占用时排队等待，不再直接失败；
  - 退出时记为"中断"而不是"你取消了"；
  - 示例片被你自己的音乐或录音挡住时，原因写的是音乐或录音；
  - Film 里改时长时，如果视频正在生成会提示。
- **界面**：
  - 从导演备注或检查打开的旁白编辑，保存后备注会正确结束；
  - 录音被拒时键盘焦点不再丢失；
  - 播放整场时遇到已过期的视频会跳过，不再卡住；
  - 重新生成和配音的价格在全部生成完以后也能显示。
- **导演 skills**：
  - 新增工具契约 6.0.0 和 skills v7，旧版本一字不改并加了摘要校验；
  - 提议可以改目的、动作、景别和场景标题；景别和场景标题要求简短；
  - 不再指导导演写图片 / 视频计划，生成统一走场景按钮；
  - 旁白按一次场景确认的流程说明；
  - 已有的 5.0.0 项目会自动升级。
  - 原来"就地修改 v6 会让已有项目的导演永久不能用"的问题已修好，历史锁按已发布版本的清单校验。
  - 演示用的脚本导演也改成通过提议修改。

## 对话附件和导演生成关键帧（10 月 21 日）

- **对话框附件**：
  - 支持附件按钮、拖拽到导演栏和粘贴三种方式；
  - 图片（PNG / JPEG / WebP / HEIC）、视频、音频、PDF / TXT / MD 都可以附上；
  - 每个文件先存进素材库，卡片显示上传进度或失败原因；
  - 一条消息最多 8 个文件和图片；发出的消息会列出它带的文件；
  - 导演拿到的内容：图片本身，视频的三张抽帧，音频的时长和格式，文档抽出的文字（作为材料，不当作指令）；
  - PDF 文字用 `pdfjs-dist` 5.4.296 抽取，版本固定，只在服务端用，并限时。
- **导演直接生成关键帧**：
  - 你在对话里要关键帧时，导演会直接开始生成，配音一起出；
  - 回复下方显示"已开始生成…· 约 $x"，正在生成时可以按 Stop；
  - 只有你自己发的新消息才能让导演花钱，审阅轮次不行，影片停止时也不行；
  - 视频仍然要你看过画面后逐场确认；
  - 导演也可以转写你发来的录音，同样计费并显示在对话里。
  - 这需要导演契约 6.0.0 / skills v7（未发布前直接补在上面），旧项目会自动升级。
- **验证**：`pnpm test` 3,878 通过、0 失败；浏览器 170 个场景通过（其中窄屏打开关键帧的场景偶发超时，重跑通过）。
