## 本轮（P6 之后）的审查与修复

1. **Codex web review（B17）**：15 个问题全部修复。草稿与命令绑定所属影片和基线，迟到的回复不会改写当前屏幕，付费链接都显示价格。
2. **B18**：编辑冲突改为"字段真的变了"才算冲突。之前影片版本号一动（例如别的镜头关键帧生成完）就会误报冲突、保存失败。
3. **B19**：模型提示词拼接不再出现 `on.. The`（重复句号）。
4. **视觉审查**：22 个 agent 逐张审阅 194 张截图（各视图 × 多种宽度 × 中英），150 条发现，经怀疑者复核确认 106 条（9 major）。分三轮修复：
   - 第一轮：6 个并行批次；
   - 第二轮：4 个批次；
   - 第三轮：我亲自修。
   修复内容包括：
   - inspector 在矮屏上不再切掉行或按钮，恢复操作（Give up）固定可见；
   - 镜头卡片标题和状态不再溢出；
   - 900px 宽时预览完整显示 16:9；
   - Toast 不盖住刚用过的控件；
   - 数字不再与单位断行（"6 s"、"约 $0.04"）；
   - Now / After 时间条保持按时长比例；
   - 卡片上的导演备注只从开头截断（不再挑出会误导的末尾词，如"6 s"）；
   - 中文排版的空格与标点；
   - 各种自相矛盾的状态文案。
5. **B20**：等待状态说真话。
   - 等人确认的片段不再算作"正在生成视频"；
   - 等输入或未知等待有自己的状态码；
   - 重启后结果未知的付费任务会在场景里点名，不再提供确认按钮；
   - 自己上传录音不再误报冲突；
   - 空闲时不再显示 Stop。
6. **Codex 最终 review（B21）**：6 个 P2 问题全部修复。
   - 重新生成失败时不再显示"已处理"；
   - 配音失败不再和"无需检查"并列出现；
   - 片段在等它自己的关键帧时，可以重新生成那张关键帧；
   - 字幕过长被拒绝时会显示原因；
   - inspector 重排后，键盘焦点所在的行会完整显示；
   - 播放时不再每一帧都重新测量时间线上的标签。

   我在浏览器里验证时又发现 B21 引入的一个问题：inspector 显示焦点行时会在点击中途滚动，导致点击丢失。已修复。

## 未完成与需要你决定的

1. **真实 provider 验收没做**：只用了 fixture 和假 provider。导演图片输入（B10）的实际视觉质量也未验证。
2. **卡片上的导演备注很窄时只显示字母**：完整内容在 tooltip、横幅和导演栏里。要像设计稿那样显示短标签（"Coat came out maroon"），需要导演工具返回一个 short label，是契约改动（含 skills/v6）。
3. **上传的图片没有文件名**：服务端没有存原始文件名，Assets 里显示为"Imported image 3"。要显示文件名需要后端改动。
4. **镜头重新编号后，导演备注的原文仍是旧编号**：按钮跟随新编号。这是导演自己的文字，没有改写。
5. **Toast 的位置**：在 900×800 的 Keyframes 和 Plan 视图里，可能短暂盖住一行说明文字（6 秒），已接受。
6. **被未完成编辑占用的镜头仍会让 Stop 出现**：可以撤销这项编辑，所以算作可停止的工作。如果你希望不显示，告诉我。
7. **约 48 个工作树**（`.claude/worktrees/cx-*`、`ui-*`）还在磁盘上，需要你同意再清理。
