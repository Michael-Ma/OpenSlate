# 测试说明

适用于当前合并后的 OpenSlate。旧的 `feature/last-ferry-ui` 分支、个人 worktree 路径和某次启动时间不再是前置条件。先做免费检查，再自行选择一个范围明确的真实生成测试；界面里的金额是估算，最终用服务商记录核对。

## 0. 启动与账户

从你要测试的 checkout 根目录运行，开发环境固定 Node **24.15.0**、pnpm **10.33.0**、FFmpeg/ffprobe **8.1.1**：

```sh
nvm use
pnpm install --frozen-lockfile
pnpm setup:test-media
pnpm check:toolchain
export OPENSLATE_DATA_DIR="$HOME/openslate-data"
node scripts/start-local.mjs --no-open
```

这个示例目录是新安装用的。已有影片请把 `OPENSLATE_DATA_DIR` 换成原来那一个绝对路径，并在以后每次启动时保持一致；不要移动目录。启动日志的 `Local data:` 应与预期一致。配置由本 checkout 的私有 `.env.live.local` 载入，已导出的环境变量优先。密钥只放本机服务器配置，不发到聊天或写入计划。

要换 checkout 或数据目录，先在原实例自己的终端 Ctrl+C；不要按端口批量杀进程。更新这个已验证实例时，才用同一命令加 `--restart`。打开启动日志里的配对链接。New film 有 **Storyboard** 和 **Code plan (experimental)**。

- **Codex：**按[安装说明](../../implementation/MANUAL-LIVE-PRODUCTION.md#codex)并排安装 **0.162.1** 并登录。Director 默认 **`gpt-6.1-sol`**，其他选项来自本机运行时/账户，不是写死的列表。
- **Claude Code（可选）：**本机 **2.1.312 或更高的 2.x**，使用自己的 Claude 订阅登录；可设 `OPENSLATE_CLAUDE_BINARY`。仅支持 code films，见测试 16。
- **媒体：**Codex 图片仍用 ChatGPT 登录。Viggle、Gemini/Lyria、OpenAI speech/transcription 各用自己的账户；Claude 订阅不支付这些媒体费用。
- **安全看 UI：**`pnpm studio:fixture --film last-ferry` 启动 3101 上的一次性假服务；`?fixture=last-ferry` 是另一种纯浏览器示例。两者不证明真实模型质量。

## 先测：Director 选择

### 测试 16：Claude Code 当 Director（账户额度，无媒体费用）

1. 新建 **Code plan (experimental)**，先打开空影片，不发送生成请求。
2. Settings → Models → Director 选择 **Claude Code · Opus 5.5**（`claude-opus-5-5`）或 **Sonnet 5.5**（`claude-sonnet-5-5`），Save。这里只检查版本和订阅登录，不应启动模型回合或媒体。
3. 发「先只讨论一个橘猫短片的故事，不提交生成计划，不生成媒体」。收到正常回复；回复记录标明 Claude Code，媒体花费不增加。刷新后选择仍在。
4. 新建另一部片子测试另一个 Claude 模型。不要依靠切换 Director 来重试一个结果未知的旧回合。
5. Storyboard 影片不能选 Claude Code。未安装/未登录/不是 Claude 订阅时给出可操作说明；API key 不能悄悄替代订阅计费。不要为了制造错误而退出其他会话正在使用的账户。
6. 若自愿继续真实生成，再做测试 12b；图片仍来自单独的 Codex worker，视频仍由选择的供应商生成。

### 测试 17：最新 Codex 与保存的模型（账户额度，无媒体费用）

1. 新建影片，Settings → Models → Director 的默认模型应为 **`gpt-6.1-sol`**。本机程序应报告 **0.162.1**。
2. 读取模型列表：展示本账户实际返回的模型。选择另一个确实返回的模型、Save，发一条只讨论故事的消息，确认回复和保存的选择一致。列表失败时应保留当前 ID 和失败说明，不应编造选项。
3. 打开已有且选择 `gpt-6-astra` 等模型的影片；不能因为新默认值改变而自动换模型。刷新、重启后再核对。
4. 如果你原来配置的是旧 Codex 路径，且支持的并排安装已存在，界面应说明使用 0.162.1；历史回复和媒体不改写。不要删除正在被其他实例使用的旧安装来做测试。

## 关键帧、卡片和进度

### 测试 12：上传和后续回合（上传免费；问 Director 用账户额度）

附一张普通 JPEG，再试手机 HEIC、GIF、AVIF、超过 4096 像素的图；文件内容决定格式。损坏文件和 SVG 给出明确说明，超大图按比例缩小。视频/audio 可附上，具体格式取决于本机解码器。

| 操作 | 应该看到 |
|---|---|
| 附件按钮、拖放或粘贴 | 文件块有类型/大小，Assets 能找到图片 |
| 发送「这张图里有什么」 | code-film Director 能读取图片，无「无法读取」 |
| 下一条不带附件，再问这张图 | 仍能找到已上传图片；以前上传的图无需重传 |
| 大于 4 MB 的图用作参考 | 服务器提供有归属的缩小副本，Assets 不重复计数 |

Code films 里视频和音频的后续回合查找/计划引用仍有限；不能把图片的持久可用性推广到所有附件。

### 测试 12b：每个镜头确认关键帧（真实媒体，费用先看卡片）

新建 code film，发送：

> 做一个 10 秒竖屏小片：一只橙猫在窗台上伸懒腰，然后跳下窗台。两个镜头，每个 5 秒。不要音乐、旁白或字幕。

应先有参考图和每镜头一张关键帧，再在对话出现确认卡。卡上的输入选项和价格取决于模型；支持时有「关键帧和参考图」「只用参考图」「关键帧作首帧」。**未确认该镜头前，不生成它的新视频**。点图只放大，选项才确认。Codex 图像记为 $0 估算，但消耗订阅额度。

确认一个镜头后只推进它的依赖，答案保留。说「第二个镜头换个姿势」会得到新的确认卡。声明镜头的新片段受门禁保护；旧的已派发片段重放不再购买。不声明镜头的自写计划仍不受这条门禁限制。

### 测试 12c：卡留在回复里，依赖变了才失效（不确认视频；使用 Codex 图片时媒体 $0 估算）

| 操作 | 应该看到 |
|---|---|
| 做测试 12b，先不确认 | 卡排在当时回复后面，状态条有「去确认」 |
| 问三个选项的区别 | 卡随旧回复上移，状态条可跳回；不是固定在最底部 |
| 说「故事太平淡，先给其他思路，不生成」 | Director 提交去掉旧镜头的计划后，旧卡在原位收成失效行，无可按选项 |
| 只改第二镜头 prompt/参考图 | 第一镜头的卡和答案保留；共享参考改变会影响所有依赖卡 |
| 回到逐字相同的计划/输入 | 可复用原来的图片和答案；Director 若重写 prompt，通常会生成新图片/新卡 |

撤卡依据最新完成的一次计划实际到达的选择，不是聊天关键词。Director 漏改计划时卡可能仍有效，先不要按，报告它。已失效卡不能启动生成。

### 测试 12d：Plan 能看到正在做什么

Plan 场次上方有共享 References，能打开上传图/角色图/场景图。镜头位置显示关键帧或视频「生成中」「排队中」「达到上限」；有旧结果时旧图仍在，替代进度另写。运行条说明正在生成什么，从 Assets 点它跳到 Plan。长任务显示已过分钟，超过 10 分钟提示仍在等服务，不制造百分比。

## 完整影片和修改

### 测试 1：竖屏 + 音乐（真实媒体）

新建 code film，确认上限（默认 **$4.00**；浏览器保存过偏好时沿用偏好）。发送：

> 做一部竖屏 9:16 的片子，约 12 秒，两个镜头，没有旁白。Tofu 是一只圆滚滚的开心柯基。镜头 1：坐在阳光厨房里的空碗旁，期待地盯着碗。镜头 2：特写，竖耳摇尾巴，狗粮倒进碗里。每镜头一张关键帧，等我确认后，用关键帧作首帧生成各 6 秒片段，加轻快的纯音乐，再合成。

检查竖图完整、每张卡点图可查看、Plan 与 Assets/Film 对应、视频有封面，成片竖屏且音乐实际可听。Lyria 每次按配置估算 $0.08，输出带 SynthID；视频费用以实际模式/时长/分辨率报价为准，不沿用旧 $0.10/段的数字。

### 测试 13：Tofu 同一条 brief 重拍（可选，真实媒体）

> 做一个 30s 的搞笑视频，主角是一只可爱的柯基，名字叫 Tofu，目的是发社交媒体，需要有配乐。

期望 Director 讲清笑点和预计费用，先做角色/场景参考和逐镜头关键帧，确认后买视频。若计划要求看片，运行条显示「导演在看片」；它用抽帧检查动作/剪点，再合成。观察同房间/同角色、铺垫到笑点、字幕、构图和切点；这些是人要评价的质量，不能把指引当成保证。[上次结果](../film-quality/RESULTS.md)只是一份样本。

### 测试 14：只改相关部分（真实媒体或免费重剪）

说「第 2 个镜头太慢」或「Tofu 被切掉了」。Director 说明改什么和费用，只重做有关步骤；其他片段沿用，再看片/合成。只改剪辑应尽量复用已有音乐；想保持开场构图时选「关键帧作首帧」。

### 测试 11：参考图模式和不同片长（可选，真实媒体）

在新片要求 6 秒和 8 秒两个镜头，以参考图模式生成。内置 Viggle `viggle-h3` 是 MiniMax-H3、low、768p、5–15 整秒；在这个配置下参考模式约 $0.30/$0.40，首帧约 $0.18/$0.24。检查模式、`enhance false`、9:16、输入图和实测尺寸；费用与后台分开核对。参考图模式允许重新构图，不保证从关键帧开场。当前卡片选择决定输入，不能把旧片锁定的设置当新片的默认值。

## 设置、失败和检查

### 测试 2：Developer mode（免费）

Settings → This computer → **Developer mode** 开启后，code film 出现 Code 标签和实际调用参数。关闭后 Code 消失，停在 Code 时返回 Plan。普通界面仍能查看完整 prompt、模型和媒体事实。

### 测试 3：Spend limit（免费）

1. This computer → **Spend limit for new films** 改成 3，新建 code film 显示 $3；这项和 Developer mode 是浏览器偏好。
2. Settings → Director → **This film's spend limit** 或运行条上的修改，调整本片上限，刷新仍保存。
3. 降到已花、可能已花和已开始金额之下应被拒绝，不能丢掉旧任务责任。
4. 自己发「把这部片上限改为 $5」，Director 才能引用这条消息修改并给回执。修复/看片等应用回合不能借用这次同意。

### 测试 4/5：失败与重试（遇到真实失败时测，不主动断网）

Film/运行条/影片列表指出需要处理，说明失败阶段、能否安全重试、可能费用。已证明未提交的错误最多自动安全重试两次；仍不明确的提交保留原身份和责任。Viggle 无状态/无任务 ID 的丢回复可先做两次有界账户检查；发现陌生任务或覆盖不完整仍不能当免费失败。

对于可能收费的 **Retry**，先看双重收费说明再自行决定。不要为了测试关掉这台共享机器的 Wi-Fi，不要因长时间等待就盲目重发。记录原 attempt/task，再核对重启后是否仍是它。

### 测试 6：Seedance 和 fal（需自己的 key/开通，单独选择范围）

按[适配器配置](../../technical/PROVIDERS-ARTIFACTS.md#n2-video-models-offline-implementation-october-30-2026)配置 `OPENSLATE_MODELARK_API_KEY` / `OPENSLATE_FAL_API_KEY` 和 profile catalog；不要在文档写 key。是否能用由账户/模型/地区决定，本地适配器通过不等于已获得访问权限。重启后新建 code film，选择 `seedance-mini` 或 `fal-kling` 等实际安装的 profile，只做一个短镜头。旧片锁定的模型列表不自动加入新模型。

### 测试 7/8：Assets、prompt 与视频参数（免费）

Assets 区分参考图、关键帧、视频、音乐和成片，封面不混算为关键帧。按场景/镜头过滤，能看当前/历史结果。点图或视频打开 viewer，←/→ 切换，Esc 关闭。右侧完整 prompt 可复制；Developer mode 增加过滤过的调用参数（输入模式、裁切、比例、尺寸、任务 ID），普通模式不显示密钥或内部路径。数量来自本片，不要求固定的旧 Tofu 数量。

### 测试 9/10：状态与比例提示（免费）

人是蓝色、Director 是琥珀色；运行紫色、完成绿色、等待琥珀色、失败红色，费用青色；接近/达到上限有变化。中英文、桌面/手机均要能看清。Code Film 的 cover 裁切严重时应提示保留画面比例；符合比例的新片不能因为旧 Tofu 片的数据而显示固定「32%」。

### 测试 15：查看已有成片（免费）

在你原来保存该片的数据目录打开 Film。需要切数据目录时，先停止自己已确认的实例，再用第 0 步同样的启动方式；不要依赖某个旧 worktree 或个人目录名。观看本地文件不启动新的生成。

## 已知边界

- Director 可以看图片/视频 contact sheet，**听不到音频**。配乐、音效和语音需人听。
- 每部片的自动看片最多 4 次；补拍次数主要靠指引和上限限制。
- 音效是六个本地合成音（pop/thud/whoosh/ding/tick/boing）；字幕需本机合适字体。供应商片段原音会被去掉。
- Lyria 时长不精确，要裁剪淡出。只改剪辑尽量复用，计划不同的 duration/variant 可能改变身份。
- Viggle 处理时间波动大。长等待不是失败或重复购买的证据；实际费用看供应商记录。
- 新默认 $4 不覆盖已存上限/偏好。旧模型锁、旧输入和历史费用不回写；引导能按兼容规则在新回合刷新，不必一概重建旧片。
- code films 的 source 只读当前版本给 Director；它重写旧方案时 prompt 稍有变化便可能产生新关键帧。
- 未实现：由录音新建声音克隆、通用多轨编辑器、跨机器部署/便携数据迁移。已有自定义 voice ID 与新建克隆是两回事。
