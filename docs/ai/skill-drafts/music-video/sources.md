# Sources

Consulted 2026-10-28. Most practical sources are blogs, forums, vendor pages and course material, not peer-reviewed craft references. The ratio ranges, tempo tables and per-instrument mitigations in these drafts are working heuristics from these sources plus general production knowledge, not measured standards.
