# Generation, review and spending

Writing or revising the film does not require permission to spend on media. OpenSlate asks for concrete decisions when it is about to create a creative result, use an account or condition video on a returned frame. These decisions should be explained in the flow where they matter, not presented as repetitive configuration warnings.

| Decision | Meaning |
|---|---|
| Generation permission | Human origin for one selected operation kind per shot/request; a model cannot mint another creative take |
| Usage/spending allowance | Finite starts and configured-estimate cap for exact candidate/profile/specification work |
| Keyframe/motion approval | The actual returned conditioning image and effective video motion/specification are accepted for that video |
| Audio acceptance | The exact words/description, recording and source range are accepted; no additional API call is authorized |
| Project budget | Separate application-level cap over committed estimates; an allowance cannot raise it |

A narration guidance/tool upgrade is a compatibility update. It is neither audio consent nor a spending grant. Existing voice registration requires separate explicit consent; ordinary script writing does not.

## Exact allowances

The browser reviews work for one saved profile at a time. A review freezes candidate/node/spec identities, full profile digest, allowed starts, configured estimate and expiry. The server checks current matching authority, readiness, control/hold state and remaining allowance during atomic admission. Consumption stays durable across restart; revocation blocks future starts without refunding prior work.

The UI normally offers one start per selected candidate with a 24-hour expiry. The backend supports bounded finite expiry. Historical projections resolve retained original model/work definitions, rather than substituting today's shot text or catalog. Protected scripts, paths, credentials and result locators stay out of spending summaries.

Cost estimates are host configured; they are not live vendor quotes, guaranteed charges or an account-wide cap. Codex image permission bounds native starts; internal image-call/quota consumption is unknown. Its zero direct USD image charge is not a claim that usage is free/unlimited.

## Replay and budget

An uncertain issue/revoke/budget response retains its exact command identity/body for a same-command check. Server receipts remain durable even if browser state is lost. No automatic allowance increase or alternate create occurs.

Budget changes compare displayed revision and old cap, save an audit revision and retain existing liabilities. Lowering below committed estimates blocks future admission; it does not cancel or refund jobs. Unknown submission retains possible spending until positive evidence resolves it.
