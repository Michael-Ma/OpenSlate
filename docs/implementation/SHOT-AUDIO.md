# Shot audio and Film

This guide describes storyboard narration; code films instead use `ctx.speech`/`ctx.music` and render placements. Compact shot audio accepts a script first or an owned recording first. Listening needs no fabricated transcript. Acceptance requires saved words or a truthful description, exact recording binding and reviewed source range. Transcript recognition remains evidence for Director attachments; human transcript adoption has been removed.

## Exact scope and acceptance

A compact session owns one shot and an immutable section pin. Human session, project head and narration-version guards remain required. Cross-section/collection/shared-section changes require the proper explicit mapping; the session cannot borrow another request's hold.

Writing/listening/importing do not create generation permission or spending. Generated speech uses the exact requested script, voice and instructions through configured admission, without a separate usage allowance. Scene keyframe generation and the durable confirmation runner attach/accept a fitting generated line under the original human request. The keyed recording-import command likewise accepts a fitting measured recording; overlong audio remains pending free narration-fit. Acceptance freezes script revision, audio hash and source sample range; durable command replay recovers a lost result without accepting different bytes.

Within-shot voiceover fits inside a planned 3–15 second shot. A shorter nonempty range ends naturally while picture continues. Free **Make N s** / **Keep N s** commands either extend within the selected video model’s limits or keep the shot length and accept the cut range with a short fade. Undo restores compatible narration/media; no replacement synthesis is required. No source is padded or described as covering picture it does not cover.

## Canonical placement and reuse

Accepted compact audio follows its shot after reorder/earlier-duration edits. Browser/export share saved source/range/placement. Writing-only within-shot changes preserve footage, while stale generated speech is rejected at review/admission/dispatch. Successive accepted narration updates rebase only allowed audio/assembly state, retaining picture specs, reviews, attempts and grants. Canonical narration requires one pinned shot and a saved shot draft with an intent digest; it neither adopts canonical mappings as missing drafts nor accepts project-wide or absolute placements. Plan-DSL asset timelines retain their separate absolute/exact-length path until the planning layer is removed.

The owned audio library imports/listens/selects soundtrack without changing narration, holding creative work or fencing the director. Optional music is a measured owned source. Existing eligible [personal voice IDs](PERSONAL-VOICE.md) require current consent; a personal request cannot fall back to stock speech.

## Playback and export

Film plays muted picture with accepted narration/music on a shared browser clock; seek/pause/buffering and revision cleanup synchronize it. Media release and an eight-entry current/upcoming audio cache bound retained previews. Local FFmpeg uses exact integer frames/samples and supports 65 distinct audio sources/placements with eight simultaneous lanes, within 360 seconds/64 cuts.
