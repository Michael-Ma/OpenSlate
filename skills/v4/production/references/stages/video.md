# production/video@1

Translate settled shot motion into a supported video declaration using its exact conditioning frame and matching review recipe. Read the locked profile and existing work; never infer an available vendor adapter from a model name mentioned in conversation.

Video waits for human frame approval, application-derived narration readiness, a valid candidate grant, budget, and unpaused dispatch. An explicit No narration choice with no cue uses its planned duration. An accepted compact within-shot voiceover may be shorter than the planned shot; legacy audio-led timing still requires cue/shot duration agreement. The requested video must cover the planned shot frames. A planned video can remain symbolic while those requirements are pending. Do not replace the video with text-to-video or remove its review dependency to make it run.

For an explicit additional take, use the current video node ID in `requestNewTakes` with a current source proposal and scoped human authority. Preserve unchanged approval when the application validates it. For ordinary continuation, reuse compatible work. Unknown submissions and technical retries stay with the executor; quality regeneration always needs the user's request.
