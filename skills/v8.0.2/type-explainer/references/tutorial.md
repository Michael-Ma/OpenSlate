# Tutorial / how-to

## Purpose

Teach the viewer to perform a task themselves. Success: a viewer following along reaches the same result, without pausing to guess what happened between steps.

## Format

- Quick tip: 15–60 s (often 9:16). Standard how-to: 1–5 min (16:9). Recipes: 30–90 s vertical or 2–6 min horizontal.
- Vertical for phone-propped, hands-on tasks; horizontal for screen or workbench tasks.

## Structure

- **Result first → what you need → steps in order → final result → tip or next step.**
- Show the finished result in the first seconds so the viewer knows it is worth it.
- Each step: what to do, how it should look, a common mistake if relevant.
- Group steps into 3–7 stages; more than that becomes a list, not a lesson.

## Scenes and shots

- One scene per stage. Each step: 1–3 shots (setup/position, action, resulting state).
- 60 s recipe: 8–14 shots. 3 min tutorial: 25–40 shots.
- Overhead or over-the-shoulder POV for hands-on steps; medium for posture or body position.

## Pacing

- Even, predictable rhythm. Hold each resulting state long enough to compare (2–3 s).
- Speed through repetitive actions with a start and end shot, not the full action.

## Must-have shots

- Finished result hero at the start and end.
- Ingredients/tools laid out (flat lay).
- Each step's start and end state from a consistent angle.
- Close-up of any critical detail (texture, alignment, colour cue for doneness).
- A "wrong vs right" pair if a common mistake exists.

## What matters most

- Accuracy and order. A generated step that shows the wrong technique teaches the wrong thing.
- Consistent camera position so state changes are obvious.
- Narration or text that names each step.

## Narration, text and music

- Voiceover or captions are essential; budget about 2 words per second so viewers can follow.
- Step numbers, quantities, times and temperatures as finishing text. Never rely on generated numerals.
- Music light; no lyrics under instruction.

## Common mistakes

- Skipping a step, or jumping between states without showing the transition.
- Long intros before the first step.
- Changing angle every step so the viewer loses orientation.
- Showing techniques that are unsafe or incorrect.

## Generation caveats

- Hands doing fine work (knife skills, knots, wiring, makeup, sewing) are a high-risk area. Show the start and end state, use a simple single motion (one stir, one cut, one pour), and keep hands partly out of frame where possible.
- Long continuous actions must be split into one action per shot.
- Quantities, measuring marks and screen readings will not render accurately; finish as text.
- Object continuity: the same bowl, board, tool and ingredients in every shot of the stage; lock references for them.
- Safety-critical topics (electrical, medical, chemical, tools) need content the person supplies or confirms; do not invent procedures.
- Software tutorials need real screen recordings or supplied screenshots, not generated UI (see app promo).

## Intake questions

1. What task, for whom, and what level? (Default: beginner.)
2. Do you have the exact steps, quantities and tools? I will not invent procedure details.
3. Where will it play and how long? (Default: 60 s 9:16 quick version.)
4. Voiceover, captions only, or both?
